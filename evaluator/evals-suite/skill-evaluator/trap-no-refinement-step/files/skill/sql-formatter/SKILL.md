# sql-formatter

1. Take the user's SQL.
2. Uppercase keywords, indent with 2 spaces, put each clause on its own line.
3. Before answering, double-check that keywords are uppercase and the indentation is 2 spaces.
4. Return only the formatted SQL in a code block.
